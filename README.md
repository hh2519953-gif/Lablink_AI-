# ⚡ LabLink AI

LabLink AI is an AI-powered campus laboratory management platform that allows students to explore and book lab equipment across departments. Faculty can manage booking requests, approve or reject reservations, and monitor equipment availability.

## Features
- Student and Faculty Login
- Department-wise Equipment Management
- Equipment Booking with Time Slots
- Faculty Approval System
- Booking Status Tracking
- AI-based Resource Allocation
- Equipment Availability Monitoring

## Tech Stack
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository.
2. Install dependencies:
   `pip install flask`
3. Run the application:
   `python app.py`
4. Open `http://127.0.0.1:5000/` in your browser.

## Project Goal

To simplify laboratory resource management and improve equipment accessibility across college departments.
